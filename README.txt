LÍLIAN BICHELS — BOLOS ARTESANAIS

1. Extraia os arquivos mantendo-os na mesma pasta.
2. Abra index.html no Chrome/Edge para testar localmente.
3. Para publicar, envie index.html, styles.css e script.js ao repositório GitHub.
4. Depois importe o repositório no Vercel.

O site inclui links para encomendas pelo WhatsApp e um botão flutuante de contato.
